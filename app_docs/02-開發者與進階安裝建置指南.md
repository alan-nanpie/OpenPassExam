# PassExam 開發者與進階安裝建置指南 💻

本指南提供給開發者與技術人員，詳細說明如何從零配置開發環境、下載依賴、執行本機除錯以及建置 Android 與 Web 發布產物。

---

## 🛠️ 1. 環境前置需求 (Prerequisites)

- **Flutter SDK**: `^3.27.0` (Dart SDK `^3.12.0`)
- **JDK**: Microsoft OpenJDK 21 LTS (鎖定版本，嚴禁使用 Java 17 或 Java 23+)
- **Android NDK**: `28.2.13676358`
- **Docker**: v20+ (用於容器化建置)
- **Google Cloud SDK (`gcloud`)**: 建議安裝最新版並登入授權

---

## 📦 2. 專案初始化與依賴安裝

1. **複製存放庫 (Clone Repository)**：
   ```bash
   git clone https://github.com/alan-nanpie/OpenPassExam.git
   cd OpenPassExam
   ```

2. **下載 Flutter 套件依賴**：
   ```bash
   flutter pub get
   ```

3. **執行靜態代碼分析 (Linting)**：
   ```bash
   flutter analyze lib
   ```

4. **執行單元測試 (Unit Tests)**：
   ```bash
   flutter test
   ```

---

## 📱 3. Android 建置流程

### 3.1 本機除錯 (Debug)
```bash
flutter run -d android
```

### 3.2 建置 Release APK
```bash
flutter build apk --release
# 產物路徑: build/app/outputs/flutter-apk/app-release.apk
```

### 3.3 建置 Google Play AAB (App Bundle)
```bash
flutter build appbundle --release
# 產物路徑: build/app/outputs/bundle/release/app-release.aab
```

---

## 🌐 4. Web 端建置流程

### 4.1 本機 Web 預覽
```bash
flutter run -d chrome
```

### 4.2 編譯 Web Release 產物
```bash
flutter build web --release
# 產物路徑: build/web/
```

### 4.3 本機 Docker 容器化測試
```bash
docker build -t passexam-web:local .
docker run -d -p 8080:8080 passexam-web:local
# 瀏覽器開啟: http://localhost:8080
```
