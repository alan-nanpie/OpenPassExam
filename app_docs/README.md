# OpenPassExam 應用程式手冊與文檔中心 (`app_docs/`)

歡迎來到 **PassExam** 專屬的應用程式手冊與文檔中心！
本目錄專門統一存放所有關於 PassExam 的**安裝、建置、部署、操作使用與新手教學**等各類 Markdown 指南。

---

## 🤖 給未來 AI Agent 的強制規範指引 (Strict AI Directive)

> [!IMPORTANT]
> **致未來所有參與本專案開發、維護與文件撰寫的 AI Agent / 開發助手：**
> 1. **文檔集中存放原則**：凡是涉及本 App 的「**安裝 (Installation)**」、「**建置 (Build)**」、「**操作使用 (Usage)**」、「**部署發布 (Deployment)**」、「**新手教學 (User Guide)**」或「**常見問題 (FAQ)**」之 Markdown 說明文件，**一律強制放置於本 `app_docs/` 目錄中**。
> 2. **語言規範**：繁體中文文件一律採用台灣標準用語（zh-TW），嚴禁使用大陸詞彙。
> 3. **安全規範**：任何文檔中絕對嚴禁洩漏或寫入真實的 API 金鑰 (API Keys)、私鑰憑證 (Keystores / Secrets)、服務帳戶金鑰 (Service Account JSON) 等機密敏感資訊。
