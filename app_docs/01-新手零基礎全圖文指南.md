## 📱 方式二：在 Android 手機/平板上安裝 App

如果您想在 Android 手機上獲得最流暢的 App 體驗：

### 步驟 1：取得安裝檔 (`.apk`)
- 由開發者提供的官方下載連結下載最新版的 `app-release.apk`。

### 步驟 2：點擊安裝
1. 在手機的「檔案管理」或「下載內容」中找到下載好的 `.apk` 檔案。
2. 點擊該檔案，系統若提示「為了您的安全，手機目前不允許安裝未知來源的應用程式」：
   - 請點擊 **「設定」** ➔ 將 **「允許來自此來源的應用程式」** 打開。
3. 返回點擊 **「安裝」**。
4. 安裝完成後，點擊 **「開啟」** 即可開始刷題！

## 💡 常見問題與解答 (Q&A)

### Q1: 網頁打開後一片空白或一直在轉圈圈？
- **解答**：第一次打開時，系統正在下載考題與介面，通常需等待 3~5 秒。若仍無反應，請按鍵盤 `F5`（手機請下拉重新整理頁面）即可。

### Q2: 沒填寫 Gemini API Key 還能使用嗎？
- **解答**：完全可以！沒填寫 Key 時，App 會自動使用內建的 **官方詳解 + 端側離線模式** 讓您正常刷題。填入免費 Key 則能進一步享有生活化比喻、手把手 CLI 指令教學等旗艦動態思考推理。

### Q3: 刷題需要一直連著網路嗎？
- **解答**：基本考題練習具備離線快取功能；但若要使用 **Gemini 3.7 Flash AI 智慧即時家教** 進行即時提問互動，需要保持網路連線。

### Q4: 畫面字體太小或太大怎麼辦？
- **解答**：在 App 頂部或設定中，可以自由調整字體大小與深色/淺色模式，保護眼睛。

### Q5: 遇到問題想回報給開發者？
- **解答**：請至官方 GitHub 專案頁面的「Issues」區塊留下您的寶貴建議！
