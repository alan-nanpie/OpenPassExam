# UI/UX 設計系統 (Design System)

## 1. Material Design 3 色彩系統
- **Primary**: Google Material 藍色 (`#1A73E8`)。
- **Secondary**: Material 綠色 (`#34A853`)。
- **Error**: Material 紅色 (`#EA4335`)。
- **Surface**: 淺色 (`#FFFFFF` / `#F8F9FA`)、深色 (`#202124` / `#121212`)。

## 2. 字體排版 (Typography)
- Android / Web: Roboto 與 Noto Sans TC。
- 支援 Android 15/16 原生 Edge-to-Edge 沉浸式無邊框。
