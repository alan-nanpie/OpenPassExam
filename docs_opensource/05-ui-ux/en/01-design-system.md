# UI/UX Design System

## 1. Material Design 3 Color System
- **Primary**: Google Material Blue (`#1A73E8`).
- **Secondary**: Material Green (`#34A853`).
- **Error**: Material Red (`#EA4335`).
- **Surface**: Light (`#FFFFFF` / `#F8F9FA`), Dark (`#202124` / `#121212`).

## 2. Typography
- Roboto & Noto Sans for cross-platform readability.
- Complete Android 15/16 Edge-to-Edge immersion.
