# 貢獻指南 (Contributing Guidelines)

感謝您對 PassExam 開源專案的興趣與支持！

## 核心規範
1. **Google 生態系原則**: 本專案全面採用 Google 官方產品與服務 (Flutter, Firebase, Google Cloud, Gemini, Gemma, Google Play)。
2. **安全規範**: 嚴禁將任何 API 金鑰或憑證檔案提交至 Git。
3. **品質與測試**: 所有 PR 必須通過 `flutter analyze lib` 與 `flutter test`。
4. **在地化標準**: 繁體中文 (zh-TW) 必須嚴格遵循台灣在地網路專業術語。
